# Chapter 10: The Distribution Network

## Core Idea
After mastering one platform, expand reach by stitching multiple sites into a **content web** that funnels everyone to your email subscriber page. Each platform has different rules and behaviors — tailor the content format and the call-to-action to each, or get "skewered." Built on Harry Dry's "How I Promote My Content" (marketingexamples.com).

## Frameworks Introduced
- **The Content Web** — map every place your audience hangs out (Welsh's: Twitter, Indie Hackers, Reddit, Medium, LinkedIn, LinkedIn newsletter, Slack groups, LinkedIn stories, Facebook groups), then route all of them to one subscriber page.
- **Platform Rules (per Harry Dry)** — match format + CTA to behavior:
  - **Twitter, Reddit, Indie Hackers** → long-form article sharing with a *polite* ask to join the email list at the end.
  - **Facebook groups, Slack groups** → break the article into **visual snippets** with a **subtle CTA** (URL/handle tucked in a corner). Don't ask aggressively.
  - **Hacker News, Designer News, Growth Hackers** → **direct links** only (Welsh doesn't use these).
- **Welsh's Three-Box Routing**:
  - **Red box** (Slack channels, LinkedIn stories, Facebook groups) → post an image/snippet that drives to a **Twitter thread** → thread has the polite email ask.
  - **Yellow box** (Twitter thread, LinkedIn newsletter, Indie Hackers, Reddit, Medium repost) → long-form with a polite CTA to the subscriber page.
  - **Green box** (standalone LinkedIn post) → no direct link in-post (kills reach); instead drive people to the **Featured section** link, then to the subscriber page.
- **The Bookmark System** — a "content distribution" bookmark folder where each site is labeled with its content type (snippet / long-form / direct) and CTA, so you remember the rules per platform.

## Key Concepts
- **Master one platform first** — the content web comes *after* you've mastered a primary channel (callback to Moneyball step 1).
- **Don't put links in LinkedIn posts** — it suppresses engagement; route via the Featured section instead.
- **Tailor, don't copy-paste** — one article becomes a thread, a set of snippets, or a direct link depending on the destination.

## Mental Models
- **One web, one destination** — many entry points, a single email-capture exit.
- **Respect the local rules** — each platform is a different country with different etiquette.

## Anti-patterns
- **One-size-fits-all posting** — same format everywhere gets you punished by platform norms.
- **Aggressive asks in Slack/Facebook groups** — use subtle CTAs there.
- **Direct links inside LinkedIn posts** — tanks reach.
- **No system to track the rules** — you'll forget which site wants what; build the bookmark folder.

## Key Takeaways
1. Find where your audience hangs out; map a content web to one subscriber page.
2. Match format + CTA to each platform's behavior (long-form / snippet / direct).
3. Route LinkedIn traffic through the Featured section, not in-post links.
4. Build a labeled bookmark folder so the rules are always at hand.
