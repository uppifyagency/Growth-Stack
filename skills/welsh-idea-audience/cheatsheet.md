# Idea to Audience — Cheatsheet

## The Five-Step Plan (= the 4 sections, IAPP)
`Audience → Service business → Serve & learn → Productize → Shift to scalable products`
Sections: **Idea → Audience → Proof → Product.**

## The Three Ways to Ideate
| Way | Verdict |
|---|---|
| Product-led | worst — most can't build; outsourcing = risk |
| Solve your own problem | good *only if you already have distribution* |
| **A Niche of One** | best — skill × interest = a micro-niche you own |

## A Niche of One Equation
`Skill × Interest → Unique Idea → Service Business → Product`
Neither input is unique; the *combination* is. Zero competition + built-in distribution.

## Six New Rules of Internet Money
Scale · Diversify · Invest · Replicate · Increase · Compound — each a "______ yourself" prompt.

## The Comfort → Growth Zones
`Comfort (safe) → Fear (hurts most) → Learning (new skills) → Growth (purpose)` — growth requires crossing the fear zone.

## Play Moneyball — 5 Steps
1. One platform · 2. Daily relevant content · 3. Social ecosystem (adjacent + contrarian) · 4. Notifications / activity-page hack · 5. Tools (SparkToro) to find where they play.
**Get on base daily. Ignore virality. Siphon bigger audiences.**

## Content Formula (per-post gut check)
| Basic | Great = |
|---|---|
| Outcome | one specific action |
| Focus | sniper (not sprayer) |
| Structure | rotating combo; double down on what works |
| Opinions | strong + authentic |

## Content Matrix (5 layers)
`Mantra → Taglines → Pillars → Core Concepts (strong opinions) → Structures`
Combine a core concept × a structure → a post. Say one thing 15 ways.

## Scroll Test — 4 Levels
L1 consume only · L2 create, can't break scroll · L3 pattern interruption + traction · L4 auto-consumed.
Text: hook line 1, crave line 2. Images: anti-stock-photo. Video: short, eye-catching.

## Art of the Capture (landing page, ≤3s)
Bold statement → secondary header → social proof (subscriber count) → **one** bold CTA. Less is more. No stock photos. White space.

## Content Web — format by platform
| Platform | Format + CTA |
|---|---|
| Twitter / Reddit / Indie Hackers | long-form + polite ask |
| Slack / Facebook groups | visual snippets + subtle CTA |
| HN / Designer News / Growth Hackers | direct link |
| LinkedIn post | route via Featured section (no in-post link) |

## Service Business — 3 Levels & 7 Components
**Levels:** L1 low-cost/learn → L2 industry-average → L3 high-price micro-niche.
**Components:** website · service description · FAQs · inquiry form · booking · rate sheet · payment processing.
**Automation rule:** task >$100/hr value or >10-15 min/day routine → automate (Carrd + Airtable + Stripe + Zapier; 35-45 min → ~4 min).

## F.I.T.I (raise rates)
**F**eedback → **I**teration (love × need crossroad) → **T**estimonials (ruthless) → **I**ncrease (double price / half win-rate = same money, half time). Welsh: $250 → $2,500/hr.

## Move Fast & Cheap — 4 Steps + Four-Pass
1. Narrow topic (teach in sleep) + time-box 2 wks · 2. Outline (sections → chapters, 1-2 outcomes) · 3. Four-Pass · 4. Feedback.
**Four-Pass:** brain-dump → notes + bullet summaries → media → resources.

## 14-Day Pre-Sell Launch
Day 1 set up + announce (discount $99→$149) · Days 2-9 Four-Pass build + day-8 teaser · Days 10-13 review, screencasts, write-up, testimonials, buyer-flow check · Day 14 **blitz** social + distribution + email · post-launch collect testimonials + raise price.

## Operating Maxims
- Play the long game (~1 yr to traction).
- You only need to be **one chapter ahead**.
- The **market decides** — no permission needed.
- **Get on base**, don't swing for home runs.
- **Low production, high access, high affordability.**
- **Time is the ultimate currency** — automate the rest.
