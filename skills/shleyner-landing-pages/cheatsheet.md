# Cheatsheet — Transformational Landing Pages

## CDCA — the 4 jobs (every page)
**Clarity** (Ch 2) → **Desire** (Ch 3–4) → **Credibility** (Ch 5) → **Action** (Ch 6). Test it (Ch 7).

## The Hero divider (6 elements, in order)
1. **Primer** — what it is, plainly, ends with a colon
2. **Headline** — one big, beautiful promise; clear not clever
3. **Subhead** — Future Pace ("imagine / stop / start")
4. **Body** — answer "how?" in ~20–30 words
5. **CTA** — incentive (urgency)
6. **Art** — visualize what you get + reinforce incentive
→ Each pulls the eye to the next = **Slippery Slide**. Hero must "earn the scroll."

## Worked example — "Write copy, confidently" (Scientific Advertising)
- **Primer**: "A short, 100-year-old book, declared essential reading for modern copywriters:"
- **Headline**: "Write copy, confidently."
- **Subhead**: "Stop feeling like an imposter. Start thinking, writing, and selling like a professional conversion copywriter."
- **Body**: "This concise, 53-page book—packed with timeless, proven persuasion principles and techniques—will teach you how to create ads you're proud to deliver to clients."
- **CTA**: "Buy Now → Save 50% — Don't delay. Flash sale ends tomorrow." (+ downsell: "Read Chpt. 1 → Free")

## 9 Fascination Rules
1. Write more than you need (7×) · 2. More specific benefit = better · 3. Prove it (specifics + credible source) · 4. Clarity beats concision · 5. Simple words (≤2 syllables) · 6. Use the prospect's vocabulary (expert audiences) · 7. Avoid "buy/purchase" → "get" · 8. Avoid "learn/study" → "discover" · 9. Create variance (layout + filters).

## 18 Fascination Filters (angle → cue)
1 Mechanisms ("system/tech" in quotes) · 2 Statement+Interest+Benefit · 3 "What…" · 4 "What never…" (fear) · 5 "Right? Wrong…" (debunk) · 6 "Why…" · 7 "When…" · 8 Specific question · 9 "If, then…" (self-ID) · 10 "Quickest, easiest…" · 11 Number · 12 Big promise (verb-led) · 13 "How…" · 14 "Caution…" (fear) · 15 "Truth…" · 16 "Best…" (ego) · 17 "Surprising…" · 18 "Are you…" (FOMO).

**3-step process**: find the nugget → tease value & state benefit (If/Then) → apply a filter. Practice via **copyworking**.

## Credibility
- **Confidence signals**: Logos ("worked for them") · Guarantee ("I believe in myself" — transfers risk) · Statistics ("trust the numbers"). Show proof **high** on the page.
- **Testimonials**: **Whale** = one credible name (reputation transfer) · **School** = wall of many (LISH). No testimonials? Tool + incentivized ask + bake into content.

## Compelling Action — "Why now?"
1. **FOMO** (time/supply-limited economic incentive) · 2. **Easy** (fewest form fields) · 3. **Nothing to lose** (guarantee + optional downsell) · 4. **Because you're asking** (one CTA per divider, stand-out color).

## Testing
**Big test first** (page that looks nothing like the control) → run to **significance** → if win, contender becomes control → **small tests** (one variable; favorite = the incentive). If lose: revisit person/angle, rewrite Hero hook, retest. *"Failing often and testing big differences shows you're doing enough."*

## Rules of thumb
- Build the **page first**, then the ads (Transitional Congruence).
- Write to a **person (Andy)**, never a **persona (Jane)**.
- **Clarity beats clever**, always. Aim to **double**, not lift 1%.
