# Chapter 9: Step 6 — Map the Attributes to Value "Themes"

## Core Idea
Customers don't care about features; they care about what features do for them. Translate each attribute into value, then cluster the value into a few themes.

## Frameworks Introduced
- **Feature → Benefit → Value chain**:
  - **Feature**: what your product has/does ("15-megapixel camera").
  - **Benefit**: what the feature enables ("sharp photo images").
  - **Value**: how it maps to a goal the customer is trying to achieve ("images zoom or print large and still look sharp").
- **Cluster value into themes**: group attributes that deliver similar value from the *customer's* perspective. Aim to shorten the list to **1–4 value clusters** (sometimes just one).

## Key Concepts
- **Value (and proof)**: the reason someone cares about your secret sauce — must be as fact-based and provable as possible.
- **Value theme**: a customer-perspective grouping (e.g. "works on any device" + "works offline" → "supports remote environments").
- **The "So what?" test**: if you state a feature ("patented fuzzy-logic algorithm") and the reaction is "so what?", you haven't reached value yet. Push: feature → faster response times → respond to *their* customers live on the phone → higher satisfaction.

## Mental Models
- Technical people conflate features and benefits because they translate to value automatically in their heads (megapixels → photo quality). Most customers won't do that translation for you — make value explicit.
- "The stone age didn't end because they ran out of stones." Don't anchor on the feature; anchor on the value/outcome.

## Anti-patterns
- **Stopping at benefits** without connecting to a customer goal.
- **Highlighting every little feature customers love** — positioning surfaces only the *most critical* value, front and center.
- **Subjective value claims** customers won't believe.

## Key Takeaways
1. Each feature can drive multiple value points; combinations of features can drive value too.
2. Group from the customer's viewpoint, not yours.
3. Reduce to 1–4 value themes — clarity over completeness.
