# Chapter 5: Preparation Station (The Automatic Win)

## Core Idea
Optimize your browser — your access point to the web — so you *passively* notice opportunities while doing anything online. Five setup steps that pay off forever, ending in a full worked example chaining the tools together.

## Frameworks Introduced
- **Browser-as-access-point**: since you spend so much time online, make that surface fast, organized, and instrumented.
  - How (the 5 parts):
    1. **Bookmark bar**: foldered tools (Google tools, Reddit tools, etc.) from the Tool DB.
    2. **Extensions**: install signal-surfacing tools (see below).
    3. **Shortcuts**: ⌘⇧A (tab search/home), ⌘⌥← → (move between tabs), ⌘T (new tab), ⌘L (jump to URL bar) — stop using the mouse.
    4. **Passive noticing**: enable always-on overlays so signal appears unprompted.
    5. **Use your own eyes**: whenever you see a chart you like, note and go visit its data source.

## Key Concepts (the extension stack)
- **Keywords Everywhere** (paid): inline search volume, CPC, trend data on Google/Amazon/Etsy queries.
- **Ghostery**: privacy + reveals trackers/pixels running on any site (e.g. 34 on Peak Design).
- **Wappalyzer**: reveals the tech stack a site runs on (e.g. Shopify, Apple/Amazon Pay).
- **Wikipedia XTools** (Preferences → Gadgets): page views/revisions/editors on any article (e.g. paludarium ~5K views/30d).
- **Textblaze** (text snippets), **Weva** (web clipping/highlighting).

## Mental Models
- Instrument your environment so opportunity finds *you* — most online time isn't spent actively hunting ideas, so make signal passive.
- A chart you admire is a pointer to a reusable data source — always trace it back.

## Key Takeaways
1. The end-to-end demo: arbitrary Reddit community → SubredditStats/GummySearch (size, growth, problems) → anvaka "say it" (adjacent communities/audience) → Answer the Public / Also Asked (real questions) → Google Dataset Search → Flourish (visualize). One hour, several tools, real signal.
2. Concrete find from the demo: "paludarium" had ~74K searches/mo and rising — far more than expected.
3. This Station alone justifies the course: you leave equipped for any future internet adventure.
