# VSL Mastery — Cheatsheet

## The Prospect's Question-Order (script checklist)
1. Who is this person?  2. What do they do?  3. How do they do it?  4. Is it true?  5. Can I trust them?  6. Does he get results?  7. Will this fit my situation?  8. What's the next step?
> Answer in order. A missed/early question = friction.

## VSL Skeleton (one-secret)
`Backstory → Reveal the secret (what/how/why) → Bad-vs-good examples → Quantifiable results → How-to (over-exaggerate difficulty) → Logical breakdown (numbers) → Component breakdown (the many pieces) → CTA`

## VSL Skeleton (three-secrets)
`Hook → Who am I → Pain1→Resolution → Pain2→Resolution → Pain3→Resolution → Results → Logical breakdown → Component breakdown → "I'll do it for you" CTA`
> Say "three things I do," never "three secrets."

## Follow-Up Ladder
`Email 1 → (day 3) Bump → Big Win #1 → Big Win #2 → Big Win #3 → …`  · Bump alone ≈ 30% of calls.

## The Acquisition Math
4% book (4/100) × close 25% → **100 emails = 1 client** · 5 min × 100 = **8.3 hrs/client** → send infinite emails.

## Filming Checklist
- [ ] Daylight on face, light behind camera (not artificial)
- [ ] Showered / presentable
- [ ] Show face (screen + camera); built-in webcam/mic OK
- [ ] Talk fast enough (interest set in first 3 sec), not frantic
- [ ] Expect 3–10 takes; low production value is fine
- [ ] Pipeline: Loom → Camtasia (1920×1080) → YouTube **unlisted** → embed

## Landing-Page Rules
- One continuous scroll, **no nav menus**, pure white/black background
- Order: Headline → VSL → Client interview → Results → How it works → Disqualification → Calendly
- **Carrd** ($19/yr) = high-ticket/complex · **ClickFunnels/Kajabi** = cheap productized + checkout · **Webflow** = needs-to-be-pretty
- Content > design (unless you're a design agency)

## Pricing Display
| Offer | Show price? |
|---|---|
| High-ticket / complex / non-productized | No — say "min project 3k+"; keep on swappable end slide |
| Productized / cheap subscription | Yes — pay-now (e.g., $149/mo) |

## The Two Real Levers (priority order)
1. **VSL**  2. **Live chat** (ManyChat) — *then* 3. Retargeting (backend; "helps a little")

## Retargeting Stack
Facebook Pixel (page head) + **Zapier → Conversions API** lead event on Calendly booking (beats iOS 14.5) · exclude bookers · ~$1/day Story ads, manual placements · YouTube-unlisted → Google Ads view retargeting.
