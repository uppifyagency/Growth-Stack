# The Copywriting Course — Cheatsheet

## The Course Arc
`Mentality → Core Techniques → Headlines → Cold Emails → Sales Pages/eComm → Content Marketing → Email/Autoresponders → Ads/Website/Images → Getting Clients → Products & Promotions → Blog Bootcamp → Interviews I (copy/SEO) → Interviews II (growth/email/business)`

## Copywriting Formulas
| Formula | What it is |
|---|---|
| **AIDA** | Attention · Interest · Desire · Action — type the 4 labels, one sentence each, then expand |
| **Slippery Slide** | every line's job = get the next line read (via story or education) |
| **Modified AIDA (+T)** | AIDA with Testimonials inserted = default sales-page skeleton |
| **CBI** | Competitive · Benefit-driven · Inspirational — 3 headline lenses |
| **70/30** | 70% useful content / 30% sales — every message |
| **Cold Email Outline** | intro / what it does for them / what if they get it / when can we talk |

## Headline / Subject-Line Rules
- 8/10 read the headline, 2/10 read on — the headline decides if anything is read.
- Attention triggers: new · novel · unique · helpful.
- Stuck? Steal upvoted titles (Reddit/Quora/Digg/Twitter) + combine with your angle. Relevant, never misleading.
- Subjects: short, lowercase, casual, mobile-safe, relevant — never clickbait or coupon-in-subject.
- Authentic > bombastic — the only headline that survives repeat exposure.

## Email / Autoresponder Checklist
- Sender name + past usefulness beats the subject line (A-pile / B-pile).
- Plain text or minimal centered template; never "newslettery" graphics.
- Give a lot of value before expecting money; case studies are universal fuel.
- **Follow-up** = evergreen sequence (the money-maker); **Broadcast** = one-time. Interval: 0, +1, +2, +3 days.
- Use the email AS the content; end on a cliffhanger; plan the arc on one page first.
- Whitelist/validate via PS ("reply with your problems" / "reply: I want it").
- **Constant Launch**: strip dates from launch broadcasts → load into a follow-up → evergreen.

## Sales-Page / eCommerce Checklist
- Page length = buyer knowledge: known product → button; unfamiliar → full AIDA.
- Skeleton: Headline → Interest → Desire → Testimonial → image → comparison → how-to-buy → Action.
- Store = you replicated; answer every showroom/phone question on-page (kills ~80% of support calls).
- Steal Amazon's fields incl. the **boring block**: dimensions, weight, power, box contents, shipping, compatible products.
- Each product page IS a landing page. Testimonials work by mass; price signals quality; a believable reason-why converts.
- Capture the phone number when a call is the money step.

## Teardown / Page-Review Rules
- Review backwards from the ONE goal; CTA in every section + a hard close at the bottom.
- Plain English over buzzwords; never be clever with labels ("Contact", not "AUA").
- Kill sliders/carousels — list items out. Bleary-eyes 5-sec test: is "what + what-to-do" clear?
- High CTR + low orders = broken ad scent / weak headline / buried buy button.
- Heat-map deep blue = readers quit there; fix that section, leave warm pages alone.
- One action, one link, one **BFB** (obvious from 10 steps back in 1 second). Add a bolded P.S.

## Ads / Images
- 3 AdWords rules: know the intent, to the point (no cleverness), buyers only. Fuse competitor angles into a **super ad**. Every click costs money.
- Confusing offer → literal 1-2-3 how-it-works image block.
- Transparent watermarked **PNG** for overlays; JPEG only for colored squares. Build images vertical/mobile-first.

## Getting Clients (steps)
1. First goal = exactly **$100**; the floor is $100, no ceiling.
2. Motto: **cheap, fast, dirty** — no website, no ads, no LLC.
3. Portfolio = a **Google Doc**, not a built site.
4. Post order: friends & family → Craigslist (US) / Gumtree (EU,AU) / Thumbtack-TaskRabbit (physical).
5. Flooded with leads? **Double the price** (don't delete the post). Restrict scope.
6. Cold email = 1–2 sentences → then **CALL**. Document before/after for proof.

## Products & Promotions
- Every promo = 3 emails: **Introduce → Cool Angle (proof) → Close the door** (1–2 sentences).
- Write once, reuse on emails + page + blog + auto-responder + next year. Sell while you sleep.
- Build a course in 3–4 weeks, sell forever (Terminator 2 model). Judge by buyer ROI, not completion rate.
- Buyers don't care about your LMS — WordPress + plugin / Notion / Gumroad button is fine.
- Raise prices: under-pricing kills the economics. Too cheap to discount? **Reverse Black Friday**.

## Neville's Operating Maxims
- No one cares about you — they care about themselves. Sell the benefit, not the feature.
- Write to one person ("Bob"); sell to everyone = sell to no one.
- Give-give-give, not ask-ask-ask. Casual with the suit jacket on, never the jackass.
- "Does it add to the message?" No → cut. If you're bored reading it, cut it. Undo is free.
- Earn its pixels; B2B is human-to-human; kill buzzwords with before/after + ROI.
- Own the channel: email + YouTube compound; social is rented land (FB reach 90%→~4%).
- Build the audience first, then find what to sell. Validate by selling before building.
- Deadline beats polish — just ship. 10-Year Rule: ~10 years to $1M.
