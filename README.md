# Growth-Stack

pstack applied to growth marketing.

Il comando `/growth` seleziona il playbook, apre le unità e i capitoli citati e verifica il risultato con la rubrica. Il repository include le fonti locali usate dal plugin.

## Installazione in Claude Code

```text
/plugin marketplace add uppifyagency/Growth-Stack
/plugin install growth@growth-local
```
